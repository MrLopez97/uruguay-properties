# Uruguay Properties - Test Plan

Version: 1.0
Status: Draft

## 1. Objective

Verify that the application meets its functional
and non-functional requirements.

## 2. Test Scope

### In Scope

- Property catalog
- Property search
- Property filters
- Property details
- Favorite properties
- Contact form validation
- Responsive design
- Browser compatibility
- Web accessibility

### Out of Scope

- Backend testing
- Database testing
- Authentication testing
- Real contact form submissions
- Load and stress testing

## 3. Test Types

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Exploratory Testing
- Regression Testing
- Responsive Testing
- Cross-browser Testing
- Accessibility Testing

## 4. Test Environment

- Operating System: Windows
- Browsers: Chrome, Firefox, Edge
- Development environment: VS Code
- Production environment: GitHub Pages
- Automation framework: Playwright (planned)

## 5. Entry Criteria

- Requirements are documented.
- Acceptance criteria are defined.
- The functionality is implemented.
- Test data is available.

## 6. Exit Criteria

- All high-priority test cases have been executed
  and passed.
- No critical or high-severity bugs remain open.
- Test results are documented.
- Remaining known issues are documented.

## 7. Test Status

- Not Run
- Pass
- Fail
- Blocked

## 8. Bug Severity

- Critical
- High
- Medium
- Low

## 9. Test Deliverables

- Test Plan
- Test Cases
- Test Results
- Bug Reports
- Automated Test Scripts
